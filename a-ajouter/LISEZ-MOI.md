# À ajouter au site

Dépose ici :

- **un nouveau post Instagram** (l'image PNG ou JPG, telle qu'exportée) : Claude le lit, retrouve les restos cités, crée la liste sur le site et range l'image ;
- **des nouvelles adresses** dans le fichier `adresses.txt` (une par ligne, le nom et le quartier suffisent, ex. « Kuku Chicken, Gauthier »).

Chaque soir, Claude traite ce qu'il trouve ici, met le site à jour, puis vide le dossier.
